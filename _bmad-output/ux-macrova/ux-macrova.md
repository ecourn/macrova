# Macrova — contrats UX

[DESIGN.md](DESIGN.md) définit l’identité visuelle, les tokens et les composants.

[EXPERIENCE.md](EXPERIENCE.md) définit les surfaces, les interactions, les états et les parcours.

Les décisions ont été prises par délégation de l’utilisateur, à partir de la spécification existante. Les choix non validés sont signalés comme hypothèses. Le [journal canonique](.memlog.md) conserve les arbitrages.

Le statut final désigne la clôture des contrats UX. La méthode nutritionnelle, la couverture du catalogue et les conditions de lancement restent à résoudre selon les sources produit.

Toutes les surfaces sont documentées dans les contrats ; aucune maquette n’a été produite pour cette exécution autonome. La revue éditoriale est consignée dans [review-editorial.md](review-editorial.md).

Suite : bmad-architecture pour les décisions techniques, puis bmad-ticket pour découper l’implémentation.
